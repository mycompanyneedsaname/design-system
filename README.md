## Richtungen

1. **Nachgerechnet** – Präzisionsinstrument. Papier, Anthrazit, Kupfer. IBM Plex Sans + IBM Plex Mono. Signet: Kurve mit genau einem Krümmungswechsel.
2. **Werkbank** – Handfest, nah an der Halle. Petrol, Ocker, Stahl. Roboto Slab + Source Sans 3. Signet: gerahmtes Prüfzeichen mit Knick.
3. **Kernig** – Editorial, plakativ. Schwarz, Off-White, Safran. Archivo Condensed + Public Sans. Signet: Pfeil-Wende um 180°.

Die Seite `richtungen/index.html` ist eigenständig (nur Google Fonts als externe Abhängigkeit) und kann direkt im Browser geöffnet werden.

## Nächster Schritt

Nach der Auswahl einer Richtung wird sie hier als Code-Paket (Tokens + React-Komponenten + Preview-HTML) ausgebaut, sodass `/design-sync` das System nach Claude Design hochladen kann.
